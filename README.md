# Data Engineering Bootcamp – Assignment 3

## Topic
Data Cleaning & Transformation with Pandas

## Objective
This assignment focuses on cleaning the Online Retail II dataset and transforming it into a customer-level summary suitable for customer behavior analysis.

## Technologies Used
- Python
- Pandas
- Jupyter Notebook

## Files
- `Assignment3_Data_Cleaning_Transformation.ipynb` – Complete notebook containing all phases, code, and reflections.
- `customer_summary.csv` – Final cleaned customer-level dataset.

## Dataset
Online Retail II (UK-based online gift retailer)

## Tasks Completed
- Combined multiple Excel worksheets
- Performed exploratory data quality assessment
- Cleaned invoice numbers
- Cleaned stock codes
- Handled missing customer identifiers
- Validated price and quantity values
- Engineered transaction line totals
- Aggregated customer-level metrics (Monetary, Frequency, Recency)
